## Working with External Libraries 

Bruno allows you to `npm install` your favorite packages and require() them like you would in any local project.

**This collection contains an example that uses [Zod](https://zod.dev/) to perform type-script schema validation.**

Clone this repo or just click the `Fetch in Bruno` button below! 

[<img src="https://fetch.usebruno.com/button.svg" alt="Fetch in Bruno" style="width: 130px; height: 30px;" width="128" height="32">](https://fetch.usebruno.com?url=https%3A%2F%2Fgithub.com%2Fbruno-collections%2Fexternal-libraries-zod "target=_blank rel=noopener noreferrer")

*Please note: Leveraging external libraries requires using Developer Mode. It's important to be cautious when using this mode as it allows script execution on your machine. Only use Developer Mode when you trust the author of the collection (or if you are the author, of course).*
